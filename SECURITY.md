# Security policy

## Reporting a vulnerability

Email **rareos@proton.me** with a description of the problem, the steps to reproduce it and the version you
tested (Settings > About on the device, or the release tag). Please do not open a public issue for a security
problem.

We will acknowledge the report, keep you updated while we work on a fix, and credit you in the release notes if you
wish.

## Scope

- The Rare Launcher and the Rare Wallet (key storage, signing, transaction review).
- The Rare OS image: system services, update and rollback tools, and their permissions.
- The Local API on the device.

Issues in upstream projects (Bazzite, Fedora, Steam, emulators) should go to those projects. If an upstream issue
affects Rare OS in a specific way, we still want to hear about it.

## Supported versions

Security fixes go into the latest release of the launcher and the latest stable image.
